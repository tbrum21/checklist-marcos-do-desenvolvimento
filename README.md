# Marcos

Aplicação web estática para registrar marcos do desenvolvimento infantil, baseada nos checklists do CDC “Learn the Signs. Act Early.” em português.

## Abrir localmente

Abra `index.html` em um navegador ou sirva a pasta com qualquer servidor HTTP estático.

## O que está incluído

- Checklists para 2, 4, 6, 9, 12, 15, 18, 24, 30, 36, 48 e 60 meses.
- Quatro áreas: social e emocional, linguagem e comunicação, cognitivo, movimento e desenvolvimento físico.
- Respostas “Observo”, “Não tenho certeza” e “Ainda não observo”.
- Perguntas de contexto, resumo imprimível, copiar resumo e link `wa.me` com mensagem pré-preenchida.
- Layout responsivo e folha de impressão para salvar como PDF no navegador.

## Limites de uso

O produto é uma ferramenta de acompanhamento. Não realiza triagem validada, não atribui diagnóstico e não substitui orientação profissional.

Fonte de conteúdo consultada: `Brazilian-Portuguese-Checklists_LTSAE-P.pdf` (CDC, Learn the Signs. Act Early.).
